# Успенский Водоканал — демо-прототип

Статический демо-сайт (без сервера и сборки) для показа прототипа:

- **Приложение абонента** — мобильный сценарий: вход по телефону, лицевой счёт, передача показаний, история, оплата, уведомления.
- **Панель водоканала** — веб-панель для директора, диспетчера и бухгалтера.

Сайт — рабочий экспорт из Claude Design. Страницы подгружают React и библиотеку компонентов с CDN, а экраны (`S01…S16 .dc.html`) берут из этой же папки, поэтому **через `file://` он не работает** — нужен HTTP-сервер.

## Адаптивность

- **Приложение абонента** подстраивается под любой телефон: от 320 px (iPhone SE) до 430+ px, в портретной и альбомной ориентации. Занимает весь экран (`100dvh`), учитывает «чёлку» и нижнюю полосу iOS (`safe-area`). На планшете и десктопе показывается центральной колонкой шириной до 480 px.
- **Панель водоканала** рассчитана на десктоп и планшет (в портрете и в альбомной). Брейкпоинты: от 1200 px — полный вид, таблица сотрудников; от 1100 px — форма публикации уведомления справа от сводки; ниже 1200 px сотрудники показываются карточками, ниже 1100 px форма уходит под таблицу; ниже 900 px метрики идут в две колонки. На телефоне панель тоже открывается без горизонтального скролла страницы, но основной сценарий для неё — экран от 768 px.

Стили адаптивности лежат прямо в `index.html` и `admin/index.html` (блок `<style>` в `<helmet>`), а высота и ширина экранов `S01…S16` задаются в процентах. **Важно при обновлении:** новая выгрузка из Claude Design затрёт эти правки. Не заменяйте файлы «как есть» — сравните с предыдущим коммитом (`git diff`) и верните адаптивные стили.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Приложение: http://localhost:8000/ · Панель: http://localhost:8000/admin/

## Как обновлять

1. Выгрузите новую версию из Claude Design (архив со структурой выше).
2. Замените файлы в корне репозитория содержимым папки из архива. Сама папка в репозиторий не кладётся, `.nojekyll` должен остаться.
3. Не добавляйте в репозиторий рабочие материалы (`uploads/`, `screenshots/`, `.thumbnail`, старые `PASSPORT-*.md`) — репозиторий публичный. Исключение — актуальный `PASSPORT.md` в корне: он сознательно лежит в репозитории (без секретов и реальных данных), обновляйте его вместе с кодом.
4. Проверьте локально (см. выше), затем:

   ```bash
   git add -A
   git commit -m "Update demo"
   git push
   ```

5. GitHub Pages пересоберёт сайт за 1–3 минуты. Если на телефоне видна старая версия — обновите страницу с очисткой кэша.

Настройка Pages: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, folder `/ (root)`**.

## ⚠️ Важно

- **Все данные вымышленные.** Абоненты, счета, показания, платежи, телефоны, почты и адреса выдуманы для демонстрации. Не вносите в демо реальные персональные данные, номера счетов и платёжные реквизиты.
- **Репозиторий и сайт публичные.** Всё, что в нём лежит, доступно любому в интернете и остаётся в истории git, даже если файл потом удалить. Не добавляйте пароли, токены, ключи, внутренние документы.
- **Вход в панель ненастоящий.** Это демо-режим без проверки паролей и без серверной части, реальной защиты у панели нет.
- Это прототип: оплата, СМС и интеграции с биллингом не работают по-настоящему.
