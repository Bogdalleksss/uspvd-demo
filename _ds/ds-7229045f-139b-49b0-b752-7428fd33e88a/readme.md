# Успенский Водоканал — дизайн-система

Дизайн-система мобильного приложения для абонентов МУП «Успенский Водоканал» — муниципального предприятия водоснабжения и водоотведения в с. Успенское, Краснодарский край. Приложение решает три задачи абонента: передать показания счётчика воды, оплатить квитанцию, узнать об отключениях воды.

**Аудитория:** жители сельского поселения, среди них много пожилых людей. Отсюда крупный шрифт (18px основной текст), простые слова вместо канцелярита, предсказуемые сценарии без скрытых жестов и без сообщений, исчезающих по таймеру.

## Источники

- `uv-ds/` — готовая дизайн-система, переданная как локальный каталог: `DESIGN.md` (полный текст правил), `tokens.json`/`tokens.css` (точные значения токенов), `components.html`/`components.css` (эталонная разметка всех компонентов), `components/<Имя>/README.md` (правила по каждому компоненту).
- `uploads/uv-lockup.png`, `uploads/uv-mark.png` — исходные файлы логотипа (тождественны `uv-ds/logos/`).

Все цвета, размеры шрифта, отступы, скругления и тени в этой дизайн-системе взяты из `uv-ds/tokens.json` и `uv-ds/DESIGN.md` без изменений.

## Компоненты

12 компонентов, воспроизведённых по `components.html`/`components.css` и README каждого компонента — полный набор, определённый источником:

**Формы:** Button, TextField, OTPField, ReadingInput
**Данные:** AccountCard, NotificationCard, BarChart
**Обратная связь:** StatusBanner, Dialog
**Навигация и списки:** ListRow, TabBar, TopBar

Каждый — в `components/<Имя>/`: `<Имя>.jsx`, `<Имя>.d.ts`, `<Имя>.prompt.md` и карточка `*.card.html` для вкладки Design System.

## Содержание проекта

- `styles.css` — точка входа: подключает все токены и базовые стили из `tokens/`.
- `tokens/` — `colors.css`, `typography.css`, `spacing.css`, `radius.css`, `shadow.css`, `size.css` (переменные), `fonts.css` (Open Sans + Material Symbols Rounded с Google Fonts), `base.css` (готовые CSS-классы всех компонентов — `.uv-btn`, `.uv-field`, `.uv-card` и т.д., перенесённые из `components.css`).
- `components/` — 12 директорий компонентов (см. выше).
- `ui_kits/mobile-app/` — клик-через прототип приложения абонента: вход по телефону/коду из SMS → главная → показания → платежи → уведомления → «Ещё» с выходом.
- `guidelines/` — карточки фундаментальных стилей (цвет, типографика, отступы, скругления, тени, иконки, логотип) для вкладки Design System.
- `assets/` — `uv-lockup.png` (знак + название), `uv-mark.png` (знак-капля).
- `thumbnail.html` — плитка проекта.

## Содержание и тон текста

- Обращение на «вы» со строчной буквы, без восклицательных знаков и без эмодзи.
- Кнопки называют действие глаголом: «Передать показания», «Оплатить 1 248,60 ₽» — не «ОК», не «Далее».
- Ошибки говорят, что делать: «Новое показание не может быть меньше прошлого (00123). Проверьте цифры на счётчике» — а не «Некорректное значение».
- Термины из словаря абонента, не из нормативов: «счётчик» (не ИПУ), «квитанция» (не ЕПД), «лицевой счёт» (не л/с), «горячая линия» (не контакт-центр).
- Заголовки и подписи кнопок без прописных букв — прописные читаются хуже, хотя на сайте водоканала меню набрано прописными.
- Числа: суммы с пробелом-разделителем тысяч — «1 248,60 ₽»; показания с ведущими нулями, как на табло счётчика — «00131 м³»; даты словом — «до 25 сентября».
- Одно главное действие на экран: всегда одна кнопка `primary`, внизу экрана, в зоне большого пальца.

## Визуальные основы

- **Цвет.** Главный цвет действий — `primary` (#0D6393): заливка главной кнопки, ссылки, активная вкладка, фокус. Фирменный синий сайта `brand-blue` (#1689CB) — только декор, иллюстрации, иконки и текст крупнее 24px; никогда как обычный текст или заливка кнопки с белой подписью (контраст 3.84:1, ниже порога для текста). `brand-red` — только внутри логотипа. Статусы — пары `*-soft` фон + текст/иконка того же тона; статус всегда подтверждён словом и иконкой, не только цветом.
- **Типографика.** Один шрифт — Open Sans (шрифт сайта водоканала). Основной текст 18px (`body`) — крупнее платформенных умолчаний iOS/Android, осознанно для аудитории. Суммы — `display` (32px/700), показания счётчика — `reading` (40px/600, табличные цифры). Есть переключатель «Крупный текст» (×1.25).
- **Сетка.** Шаг 4px. Экран — 390×844 (iPhone 14/15), вёрстка тянется 360–430. Любая зона нажатия ≥ 48px (`size-touch-min`), высота кнопок/полей/строк — 56px (`size-control`).
- **Формы.** Скругления: 12px у кнопок/полей/карточек/баннеров, 20px у листов и диалогов. Одна тень у карточек (`shadow-card`), одна — у листов/диалогов/панели (`shadow-sheet`). Никаких цветных полос по краю карточек и декоративных градиентов — фирменный градиент допущен только тонкой полосой в шапке экрана приветствия.
- **Фон и поверхности.** Экран — `bg` (#F3F6F9), карточки и поля — `surface` (белый). Только светлая тема.
- **Анимация.** Минимальная: спиннер загрузки в кнопке. Никаких decorative-анимаций, bounce, parallax — приоритет предсказуемости для аудитории.
- **Иллюстрации/фото.** Не используются — ни фото, ни full-bleed изображений, ни паттернов/текстур. Экраны только из текста, компонентов и иконок.

## Иконография

- Единственный набор — **Material Symbols Rounded**, 24px, вес 400, загружается с Google Fonts (`icon_names=...` в `tokens/fonts.css`, тот же список, что в `uv-ds/components.css`). У водоканала своего набора иконок нет; Material Symbols выбран как открытый и одинаково доступный на iOS и Android.
- Контурный стиль — по умолчанию; заполненный (`uv-icon--fill`) — у активной вкладки TabBar и у иконок статусов (info/success/warning/error).
- Иконка никогда не единственный носитель смысла — всегда рядом текстовая подпись.
- Эмодзи и unicode-пиктограммы не используются.

## Логотип

- Только исходные PNG из `assets/`: `uv-mark.png` (знак-капля) и `uv-lockup.png` (знак + название). Не перерисовывались.
- Знак — экран приветствия и вкладка «Ещё»; горизонтальный блок — экран приветствия и экран входа.
- Только на белом фоне (`surface`), без обводок, теней и перекраски; поле вокруг не меньше половины ширины знака.

## Дизайн-система iOS/Android

Бренд, цвета, шрифт, компоненты и нижняя панель одинаковы на обеих платформах — платформенными остаются только механики (жест «назад», стиль системных диалогов, автоподстановка кода из SMS). Подробности — `uv-ds/DESIGN.md`, раздел «iOS и Android». Прототип в этом проекте выполнен в едином виде 390×844.

## Ограничения и открытые вопросы

- Шрифт Open Sans подключается с Google Fonts CDN (как в источнике) — не встроен как файл. Если нужен офлайн/self-hosted шрифт, дайте знать — заменю на `@font-face` с локальными файлами.
- Material Symbols Rounded также подключается с Google Fonts CDN, ограниченным набором имён иконок из источника.
- UI-кит покрывает 6 экранов (вход, главная, показания, платежи, уведомления, ещё) — если нужны другие сценарии (например, история платежей отдельным экраном, редактирование телефона), уточните, добавлю.
